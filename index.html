▪ Own This App on GitHub Pages

🌐 What you'll get

A permanent URL like gprsadvisory.github.io/scorecard — free forever, works offline, installs on any phone like a real app. Takes about 10 minutes.

📋 Step-by-step guide

1

Create a free GitHub account at github.com if you don't have one. Use your GPRS email.

2

Create a new repository — click the + icon → New repository. Name it: scorecardCopy

Set it to Public. Tick "Add a README file". Click Create repository.

3

Upload the three files — click "Add file" → "Upload files". Drag and drop all three files:

GPRS_Meeting_Scorecard_App.html
manifest.json
sw.js

Then rename the HTML file to: index.html (click the pencil icon after uploading)

4

Turn on GitHub Pages — go to Settings → Pages → Source → select "Deploy from a branch" → choose "main" branch → click Save.

5

Your app is live — after 2–3 minutes, your URL will be:

https://[your-username].github.io/scorecard

Share this link with George P and George N. They can install it on their phones from the browser.

6

Install on phone (iOS) — open the URL in Safari → tap the Share icon → "Add to Home Screen" → tap Add. The GPRS app icon appears on the home screen.

7

Install on phone (Android) — open the URL in Chrome → tap the three dots menu → "Add to Home Screen" → tap Add. Works instantly.

💾 About your data

Meeting logs save to each person's phone/browser locally. To centralise all logs — each person exports their CSV weekly and sends to Su for HubSpot import. This keeps everything in one place without needing a server or database.

🔗 Once on gprsadvisory.com.au

Once your website is live, these three files can be added to a /scorecard folder on your own domain — giving you a URL like gprsadvisory.com.au/scorecard. Most professional option long term.
